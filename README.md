# Kreeda-Prerana Scout

Kreeda-Prerana Scout is a premium Android application designed for tracking athlete performance, achievements, and upcoming events. It features a modern, glassmorphic UI, real-time dashboard display, and PDF performance reporting.

## Features
- **Premium Glassmorphic UI**: A modern and aesthetically pleasing user interface.
- **Athlete Achievements**: Automated calculation of District/State qualifications.
- **Real-Time Dashboard**: Display performance metrics and tracking.
- **Upcoming Events**: Notification system for upcoming sports events.
- **PDF Reporting**: Professional performance reports generation.

## Project Structure
The source code is organized within the standard Android project structure:
- `app/src/main/java/...`: Contains the Kotlin source code (UI, ViewModels, etc.).
- `app/src/main/res/`: Contains Android resources, layouts, and themes.

## Setup Instructions
1. Clone the repository: `git clone https://github.com/shivuaishu2004-eng/KreedaPrerana.git`
2. Open the project in **Android Studio**.
3. Let Gradle sync the dependencies.
4. Build and run the app on an emulator or physical device.
